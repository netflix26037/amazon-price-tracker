# بوت متابعة أسعار أمازون السعودية عبر تيليجرام

## الفكرة
سكريبت بايثون يفحص أسعار منتجات محددة على amazon.sa بشكل دوري (عبر GitHub Actions)،
ويبعتلك رسالة على تيليجرام لما السعر ينزل أو يتغيّر.

---

## خطوات التركيب

### 1. إنشاء بوت تيليجرام
1. افتح تيليجرام وابحث عن **@BotFather**
2. ابعتله `/newbot` واتبع التعليمات (اختار اسم ويوزرنيم للبوت)
3. هيديك **Token** شكله زي كده: `123456789:ABCdefGhIJKlmNoPQRstuVWxyz`
4. احتفظ بيه، هتحتاجه بعدين

### 2. معرفة الـ Chat ID بتاعك
1. ابعت أي رسالة للبوت اللي عملته (مثلاً "hi")
2. افتح الرابط ده في المتصفح (استبدل TOKEN بالتوكن بتاعك):
   `https://api.telegram.org/botTOKEN/getUpdates`
3. هتلاقي جزء فيه `"chat":{"id":123456789,...}` - الرقم ده هو الـ Chat ID بتاعك

### 3. رفع المشروع على GitHub
1. اعمل repository جديد (Private يفضل، مش لازم يكون عام)
2. ارفع كل الملفات اللي في المجلد ده (`check_prices.py`, `products.json`, `requirements.txt`, `.github/workflows/check-prices.yml`)

### 4. إضافة الأسرار (Secrets)
1. في الـ repo: **Settings → Secrets and variables → Actions → New repository secret**
2. أضف سرّين:
   - الاسم: `TELEGRAM_BOT_TOKEN` — القيمة: التوكن بتاع البوت
   - الاسم: `TELEGRAM_CHAT_ID` — القيمة: الـ Chat ID بتاعك

### 5. تعديل قائمة المنتجات
افتح `products.json` وضيف روابط منتجاتك من amazon.sa، كل منتج بالشكل ده:
```json
{
  "name": "اسم المنتج زي ما تحب يظهر في الرسالة",
  "url": "https://www.amazon.sa/dp/XXXXXXXXXX"
}
```
انصح إنك تستخدم رابط المنتج المختصر اللي فيه `/dp/رمز المنتج` بدل الرابط الطويل.

### 6. تجربة التشغيل يدويًا
1. روح لتبويب **Actions** في الـ repo
2. اختار workflow اسمه "فحص أسعار أمازون"
3. اضغط **Run workflow** عشان تجربه فورًا بدل ما تستنى الجدول الزمني
4. لو كل حاجة صح، هتوصلك رسالة على تيليجرام

---

## ملاحظات مهمة

- **الجدولة الافتراضية:** كل 6 ساعات. تقدر تغيّرها من ملف
  `.github/workflows/check-prices.yml` (السطر اللي فيه `cron`).
- **هشاشة الاستخراج:** أمازون بيغيّر تصميم صفحاته بين فترة وأخرى، فممكن السكريبت
  يفشل في إيجاد السعر لمنتج معيّن. لو حصل كده، شوف رسالة الخطأ في تبويب Actions
  (جوه تفاصيل التشغيل) وابعتهالي عشان أظبط طريقة الاستخراج.
- **الحظر المحتمل:** لو أمازون بدأ يرجع صفحات تحقق أمني (CAPTCHA) بدل صفحة المنتج،
  معناه إنه لاحظ نشاط آلي. الحل: قلل عدد المنتجات، أو زود الفاصل الزمني بين الفحصات،
  أو زود عدد الساعات بين كل تشغيل.
- **الملف `prices_history.json`:** بيتولد تلقائيًا ويتحدث بنفسه بعد كل تشغيل، مش
  محتاج تعدله يدويًا.
- هذا الاستخدام شخصي وبسيط (متابعة عدد محدود من المنتجات)، وليس أداة استخراج بيانات
  بكميات كبيرة.
